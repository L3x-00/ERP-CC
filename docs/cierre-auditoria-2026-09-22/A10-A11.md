# Cierre de auditoría — A10 y A11

Estado: corregido y comprobado **solo en el entorno local**. Este bloque no modifica datos, migraciones ni funciones de producción.

## A10 — Integración como control de entrega

El doble de `gastos-acciones.test.ts` ahora representa la lectura real de `configuracion_sistema` antes de registrar un gasto. Comprueba tanto el camino válido con el catálogo predeterminado como el rechazo de una categoría ausente del catálogo. Antes, la prueba devolvía un error genérico porque el doble carecía de `from`.

`pnpm test:integracion` comprueba primero que existen URL y claves explícitas del stack local y que la URL apunta a loopback. El job de CI exporta y comprueba el destino de `supabase status`, provisiona el fixture local y ejecuta **toda** la suite de integración antes de E2E; un fallo interrumpe el job. En el stack local actual, la suite pasó **18 archivos, 161 casos, cero fallos y cero omisiones**. Esto no demuestra todavía el resultado de un job remoto de GitHub Actions: el cambio no se ha publicado.

## A11 — Aislamiento de datos de QA

Las pruebas de integración con clientes reales comparten una utilidad que toma credenciales solo de `process.env`; nunca lee `.env.local`. La utilidad rechaza una URL no loopback al cargar el test, antes de crear un cliente. La suite genérica exige además las tres variables necesarias y falla antes de iniciar Vitest si no hay stack local. Los dobles sin base real permanecen ejecutables de forma focal.

Las semillas mutadoras de QA conservan la prioridad de las variables explícitas sobre `.env.local`, pero comprueban el destino antes de crear un cliente o enviar una petición. `e2e-local.mjs` pasó de un aviso tardío a bloqueo previo. La verificación SQL del motor usa `supabase db query --local` en lugar de `--linked`. Se retiró la excepción por variable que permitía saltar la protección de loopback. El configurador de Playwright exige URL de Supabase y del navegador locales antes de importar los escenarios E2E, incluidos los que leen `.env.local`.

Pruebas negativas con URL remota ficticia demostraron bloqueo previo de integración y Playwright, sin peticiones a esa URL. Siete semillas mutadoras rechazaron ese destino antes de conectar. La suite focal de aislamiento y gastos pasó **92/92**. Tipos, lint, compilación y **716/716** pruebas unitarias pasaron; Playwright enumeró 26 escenarios y ejecutó **1/1** flujo de contactos con entorno local. No se repitió la batería E2E completa de producto A07–A09 porque este bloque no cambia producto. La ejecución del CI en GitHub y la aceptación remota siguen pendientes de publicación autorizada.
