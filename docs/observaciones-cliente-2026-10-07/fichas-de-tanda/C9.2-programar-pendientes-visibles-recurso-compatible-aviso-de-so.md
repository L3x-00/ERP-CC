## Riesgos y mitigación
- Excluir programadas ocultaría la segunda secuencia → No se excluyen; prueba unitaria.
- Emparejamiento por nombre falla con datos sucios → Misma regla que Producción + segunda fuente maquinaAsignada; sin_dato nunca advierte.
- URI too long en .in(ids) → dividirEnLotes de 100 en toda lectura nueva.
- Doble fetch/parpadeo de la consulta de fecha fuera de rango → Reutilizar consultarCalendario, enabled condicionado, staleTime corto, RED de no disparo dentro de rango.
- pgTAP como postgres no detecta permission denied → SET LOCAL ROLE service_role para las RPC _auditada.
- Tope 300 oculta pendientes → Pendientes primero y aviso 'mostrando N de M'; cola priorizada sería APS.
