## Para qué sirve

Las **próximas acciones** son las opciones que el equipo comercial elige para dar seguimiento a una oportunidad. En lugar de escribir texto libre cada vez, se selecciona una acción del catálogo.

Ejemplos:

- Llamada de seguimiento
- Enviar cotización
- Enviar muestra
- Visita técnica

Así el seguimiento queda ordenado, se puede filtrar y no depende de cómo escriba cada persona.

## Antes de empezar

Revisa cómo trabaja tu equipo comercial. Crea solo las acciones que realmente se usan; una lista demasiado larga vuelve lenta la captura.

## Paso a paso

1. Entra a **Configuración → Catálogos → Operativos**.
2. Abre la sección **Próximas acciones**.
3. Haz clic en **Nueva próxima acción**.
4. Completa:

   | Campo | Qué capturar | Ejemplo |
   | --- | --- | --- |
   | **Código** | Clave corta, en mayúsculas y sin espacios. | `ENVIAR_MUESTRA` |
   | **Nombre** | Texto que verá el equipo comercial. | `Enviar muestra física` |
   | **Habilita texto libre ("Otro")** | Solo para la opción que permite escribir una acción distinta. | Sin marcar |
   | **Activo** | Permite elegirla en registros nuevos. | Marcado |
   | **Orden** | Número para ordenar la lista. | `6` |

5. Haz clic en **Crear**.

## La opción "Otro"

Solo **una** acción puede tener marcado **Habilita texto libre ("Otro")**. Esa opción permite que el usuario escriba una acción diferente cuando ninguna de la lista aplica.

- Deja marcada una sola opción para este uso.
- Si intentas marcar dos, el sistema rechazará el cambio.
- Puedes desactivar la opción actual y crear otra, pero no debe haber dos activas con texto libre.

## Cómo corregir o retirar una acción

- **Editar:** cambia el nombre, el orden o el texto libre.
- **Desactivar:** deja de ofrecerse en registros nuevos y se conserva en el historial.
- Si el código quedó mal, desactiva la acción y crea una nueva con el código correcto.

## Comprueba que quedó bien

- [ ] La acción aparece como **Activo**.
- [ ] El nombre se entiende sin explicación adicional.
- [ ] Solo una acción tiene habilitado el texto libre.
- [ ] El orden de la lista coincide con el uso diario del equipo.
- [ ] La acción ya aparece en el selector de seguimiento de una oportunidad.
